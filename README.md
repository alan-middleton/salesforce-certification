# Salesforce Certification Agent

## Description
This is the prompt and skills for a Copilot agent that will help you learn Salesforce and provide Salesforce certification exam like questions to validate you understanding.

## Installation

1. Create a new agent in [Copilot Studio](https://copilotstudio.microsoft.com/)
1. Set the instructions for the agent to [agent.md](./agent.md)
1. Add a skill [Salesforce-certification-quiz](./skills/salesforce-certification-quiz.md)
1. Configure a tool for [Trailhead MCP](./trailhead_mcp.md)

## Usage

```I am studying for the Salesforce integration architect certification, ask me 20 questions to test my knowledge.```
