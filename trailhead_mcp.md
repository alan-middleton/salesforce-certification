# Trailhead MCP

[Trailhead MCP](https://trailhead.salesforce.com/support/mcp)

| Settings | Value |
| --- | --- |
| Server endpoint | https://mcp.trailhead.salesforce.com/mcp |
| Authentication | No authentication required |

**content_search** — Use for discovery. Great when you know the topic but not the exact badge or trail name. Example: "Find Trailhead content on Apex testing best practices."

**fetch_content** — Use when you know exactly what you want. Pulls the full module content. Example: "Fetch the 'Apex Triggers' Trailhead badge content."
